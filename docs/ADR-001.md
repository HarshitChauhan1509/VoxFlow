# ADR-001: Why PostgreSQL

## Status
Accepted

## Context
VoxFlow needs a persistent, relational store for Users, Workspaces, Projects, Jobs, and Audio Assets. 
Because VoxFlow is a multi-tenant SaaS application, the relationships between users, workspaces, and resources are highly structured and relational. 

## Decision
We will use PostgreSQL as the primary data store, combined with Prisma as the ORM.

## Consequences
- **Advantages:** 
  - Strong relational integrity and constraints.
  - Prisma provides excellent end-to-end type safety, complementing TypeScript strict mode.
  - Easy to reason about tenant isolation (e.g. enforcing `workspaceId` on almost every table).
- **Disadvantages:**
  - Requires running a relational DB, handled locally via Docker.
  - Connection pooling limits at scale, which can be mitigated with PgBouncer if needed.
