# ADR 007: Safe Local Storage and Traversal Prevention

## Context
Handling user-uploaded files on local disk involves significant risk, specifically Directory Traversal attacks if user-supplied filenames or extensions are used blindly in file paths.

## Decision
Our `LocalStorageProvider` resolves paths securely by:
1. Deriving extensions solely from the MIME type if the parsed extension is unsafe.
2. Generating a secure `randomUUID` for the filename.
3. Explicitly resolving and checking the resulting file path against the expected `baseDir` using `path.resolve` and `startsWith`.

## Consequences
- **Positive:** Absolute protection against `../../../etc/passwd` style attacks when uploading, downloading, or deleting assets.
- **Negative:** Local storage requires disk volume management in production (which will eventually be swapped for S3, utilizing the same `StorageProvider` abstraction).
