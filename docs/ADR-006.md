# ADR 006: OpenAI Integration and Strict Schema Validation

## Context
Generating structured data (summaries, action items, sentiment) from unstructured audio transcripts requires reliable parsing from LLMs. Relying on raw string parsing from LLM outputs often leads to `JSON.parse` failures.

## Decision
We integrated the official `openai` Node SDK using `gpt-4o` with `response_format: { type: 'json_object' }`. Furthermore, we run the returned JSON through a strict Zod schema before persisting it to our database.

## Consequences
- **Positive:** Guaranteed structural integrity of AI-generated data. Invalid responses trigger a specific `MalformedOutputError` which is caught and retried by BullMQ.
- **Negative:** Adds strict dependency on OpenAI's specific formatting features and increases latency slightly due to schema enforcement.
